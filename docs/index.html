      Tonight

      Bedtime = wake time minus tonight's sleep need minus time to fall asleep. A web page cannot vibrate a band; add the bedtime to your calendar instead.

      Day so far

      Daytime stress is descriptive: each hour's heart rate above your resting baseline as 0 to 3, one level higher when a daytime HRV reading is low. Heat, caffeine, posture and illness raise heart rate too.
